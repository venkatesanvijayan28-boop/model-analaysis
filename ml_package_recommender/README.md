# ML Package Recommender

A Streamlit web app that recommends required Python packages for Machine Learning / AI models and generates pip install commands automatically.

## How to Run

1. Install dependencies:
pip install streamlit

2. Run app:
streamlit run app.py

3. Open browser and use the app.

## Features
- Model → Required Packages mapping
- Auto pip install command generation
- Download requirements.txt
- Smart project text suggestion
